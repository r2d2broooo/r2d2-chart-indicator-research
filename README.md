# r2d2-chart-indicator-research

Historical chart-indicator research, a Pine reconstruction and a written technical study.

Preserve the standalone indicator study separately from active trading rules.

## Features

- Pine Script reconstruction
- Written study report
- Original screenshots excluded for privacy
- Clearly marked historical research

## Use

Read report.md; review/import the Pine source manually in TradingView. No claim of exact equivalence or profitability.

Run `python3 check.py` for read-only source checks. These checks are not a claim
that external accounts, market feeds, hardware or a deployed service are configured.
